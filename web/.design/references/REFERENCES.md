## 关键设计 token 证据（grep 实测）

### mogu.bio —— 菌丝材料品牌站
- **缓动曲线命中**：`cubic-bezier(0.22, 1, 0.36, 1)`（grep mogu-bio.html 命中）
  → 与本项目 `--ease-soft` **完全一致**，印证"长尾缓出、安静有重量"是高端站点的通行选择。
- 文本/底色：`#32373c`（暖灰黑文本）、`#ffffff` 主底；品牌强调色落在暖橙系（`#ff4500`/`#f45800`）。
- 借鉴：菌丝主题用**低饱和暖灰黑**做主文本、**暖橙**做强调，而非冷青。

### kinfolk —— 暖调编辑风
- 底色 `#DBDED5`（暖灰绿米色）、辅助 `#f7f7f7`；文本 `#404040`/`#1c1c1c`。
- 借鉴：暖调亮色不一定要纯米黄；**暖灰绿/米灰**同样温暖且更"有空气"，文本用近黑暖灰而非纯黑，柔和不刺眼。

### awwwards / cssda —— 竞赛策展
- 作为"高质量基线"参照：获奖站普遍遵守——暖底 + 衬线大标题 + 奢侈留白 + 单一强调色 + 长尾缓出动效 + 1~2 层有机氛围。

## 对本项目「晨纸菌林」v3 的迁移要点

1. **缓动**：维持 `cubic-bezier(0.22,1,0.36,1)`（已与 mogu 实证对齐）。
2. **亮色底**：可借鉴 kinfolk 的暖灰绿米色 `#DBDED5` 思路，但本项目保持暖象牙 `#FAF6EE` 系列（与"炉边"暖意更贴）。
3. **文本**：暖近黑 `#33291F`，副 `#5C5040`——对标 kinfolk 的非纯黑暖灰策略。
4. **菌丝/蘑菇/暮光**：有机层用 SVG（菌丝细线+节点脉冲、页脚蘑菇剪影、林间暮光微光），全部 CSS/GPU 驱动，opacity ≤0.3，不打扰内容。
5. **强调色**：暖橙系（mogu 验证）——本项目余烬橙 `#B4552D` 与阳光金 `#9A6414` 同源。
