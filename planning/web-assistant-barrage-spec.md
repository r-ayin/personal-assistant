# PA Web 个人助手与桌面弹幕壳规格

- 状态：Implemented（2026-07-31，回归、浏览器、真实 CUDA、Electron 与安装器验证完成）
- 日期：2026-07-31
- 产品中枢：personal-assistant

## 摘要

PA Web 成为个人助手唯一主交互界面，覆盖聊天、助手性格、用户画像、记忆、日历、提醒、知识和设置。Electron 删除桌宠及独立后端，只保留透明置顶弹幕、托盘、打开 PA 页面和连接状态。系统只保留 PA FastAPI 后端与 PA 数据层；本地 MiniCPM-o 引擎默认关闭，仅在用户明确开启环境感知或选择本地模型时启动。

## 问题

现有 Electron 桌宠、托盘、弹幕和窗口交互不完整，桌宠形态不符合用户偏好；Electron 仍启动独立 Jarvis FastAPI、Worker、记忆和课程存储，与 PA 后端形成重复编排、重复模型加载和双数据源。PA Web 虽已有聊天、人格、记忆、日历和设置页面，但仍是控制面板结构，缺少统一、持续、可配置性格的个人助手体验。

> 用户目标：去掉桌宠，使用前端页面交互，让助手通过桌面弹幕主动说话，并可配置性格，成为完整的个人助手。

## 目标

- PA Web 成为唯一完整主界面。
- 保留全桌面透明置顶弹幕，但 Electron 仅作为无智能、无存储的显示壳。
- 单一 PA 后端、单一 PA 数据层、最多一个本地 Worker。
- 分离“用户画像”与“助手性格”。
- 主动聊天只在页面显示；提醒、主动建议、环境感知和场景陪伴才走弹幕。
- 本地引擎默认关闭，关闭感知后必须退出 Worker 并释放显存。

## 非目标

- 不保留桌宠、头像跟随、拖拽、命中测试或 `Ctrl+M` 桌宠聊天。
- 不在 Electron 中实现聊天、人格、记忆、课程、模型下载或业务设置。
- 不保留独立 Jarvis FastAPI、Jarvis 文件记忆或 Jarvis 课程库。
- 不让助手性格覆盖事实、证据、安全或提醒时间。
- 不在本轮增加多角色档案或语音形象系统。

## 成功指标

| 指标 | 目标 | 测量方式 |
|---|---:|---|
| 后端实例 | 1 个 PA FastAPI | 启动 PA 与弹幕壳后检查监听进程 |
| 本地 Worker | 0 或 1 个 | 未开启感知为 0，开启后为 1 |
| 页面聊天误发弹幕 | 0 | 主动聊天回归测试 |
| 弹幕事件投递 | 关键事件 100% | 提醒、主动建议、环境感知、场景陪伴契约测试 |
| 感知关闭资源释放 | Worker 退出且显存恢复 | 真实 CUDA 冒烟 |
| 配置一致性 | 页面回复与弹幕使用同一助手性格版本 | API 与事件版本断言 |

## 统一架构

```mermaid
flowchart LR
    Page[PA Web 主界面] --> API[PA FastAPI :8004]
    API --> DB[PA SQLite / DuckDB / Persona]
    API --> LLM[云端或本地模型]
    API --> WS[/ws/live]
    WS --> Page
    WS --> Overlay[极薄 Electron 弹幕壳]
    Overlay --> Tray[托盘]
    API --> Worker[可选 MiniCPM-o Worker]
```

### 强制边界

- Electron 只消费 PA API/WS，不启动后端、不启动模型、不访问数据库。
- PA 统一管理模型、感知、性格、用户画像、聊天、提醒、课程和记忆。
- 弹幕壳收到的事件只包含展示文本、类型、优先级、有效期和性格版本，不包含完整记忆正文。
- 本地模型不可用时明确报错，不静默切云端。

## 功能节点一：今天与对话

PA Web 首页改为“今天”，作为个人助手的默认入口。

### 页面交互

- **页面入口**：打开 PA Web 后默认进入“今天”；导航中的“今天”始终置顶。
- **展示内容**：顶部显示 PA、助手、感知和弹幕壳四个状态；中部展示连续对话；右侧或窄屏抽屉展示今日安排、提醒、近期记忆和主动建议。
- **操作项及点击效果**：点击「发送」→ 消息写入 PA 聊天记录并在当前对话区显示回复及 evidence；点击状态项 → 打开对应设置或错误详情；点击今日安排或提醒 → 打开详情；点击主动建议 → 展开依据。
- **特殊状态提示文案**：PA 离线显示“无法连接个人助手，当前内容为只读”；模型不可用显示“助手暂时无法回复，请检查模型设置”；无今日事项显示“今天暂时没有安排”。

#### 功能联动

- 当助手性格保存并启用 → 后续页面回复使用新版本，历史消息不重写。
- 当 PA 断线 → 页面停止发送操作，缓存未提交输入但不伪造回复。
- 当感知产生高置信事件 → 今天侧栏更新；页面聊天不会自动弹出或抢焦点。
- 页面主动聊天回复永不转发为桌面弹幕。

#### 异常与边界

| 场景 | 预期处理 |
|---|---|
| 重复提交消息 | 以客户端请求 ID 去重，不产生两条助手回复 |
| 发送过程中断线 | 保留用户输入并标记“发送失败”，允许重试 |
| evidence 已删除 | 显示“依据已不存在”，不隐藏该事实 |
| 长回复 | 页面内完整展示；不转为弹幕 |
| 未配置 API Token | 显示鉴权设置入口，不循环请求 |

## 功能节点二：助手性格工作室

助手性格描述“助手如何与用户相处”；自动蒸馏的用户画像描述“用户是谁”。两者独立存储、独立版本化。

### 预设

- 温柔陪伴
- 理性参谋
- 活泼搭子
- 犀利教练
- 自定义

### 配置项

| 配置项 | 取值与默认 | 约束 |
|---|---|---|
| 名称 | 文本，默认“PA” | 1–20 字，可修改 |
| 用户称呼 | 文本，默认“你” | 1–20 字，可修改 |
| 语气 | 温柔–直接，5 档 | 默认跟随预设 |
| 幽默度 | 严肃–轻松，5 档 | 默认跟随预设 |
| 主动程度 | 安静/克制/平衡/积极/陪伴 | 默认“平衡” |
| 回复长度 | 简短/平衡/详细 | 默认“平衡” |
| 弹幕风格 | 克制提醒/轻松点评/游戏搭子 | 可随预设变化 |
| 表达禁忌 | 字符串列表 | 每项 1–80 字，最多 30 项 |
| 自定义说明 | 文本 | 最多 1000 字；不能覆盖安全、事实和证据规则 |

### 页面交互

- **页面入口**：导航「助手」→「性格工作室」；今天页状态区可点击当前性格进入。
- **展示内容**：左侧预设和配置项；右侧固定展示普通聊天、到期提醒弹幕、环境感知点评三个即时预览。
- **操作项及点击效果**：点击预设 → 载入该预设参数但不立即生效；调整控件 → 本地刷新三个预览；点击「保存并启用」→ 后端校验、写入新版本并广播配置变更；点击「恢复预设」→ 清除当前未保存修改；点击「放弃修改」→ 回到当前生效版本。
- **特殊状态提示文案**：冲突时显示“这条说明与事实或安全规则冲突，请修改后再保存”；保存失败显示“性格未更新，当前版本继续生效”。

#### 功能联动

- 保存并启用 → 页面回复、主动建议和弹幕措辞统一使用新版本。
- 修改主动程度 → 弹幕策略立即重新计算，已排队消息按新规则过滤。
- 修改弹幕风格 → 只影响措辞，不改变事件类型、优先级、证据或截止时间。
- 用户画像变化 → 可影响内容选择，但不自动改写助手性格。

#### 异常与边界

| 场景 | 预期处理 |
|---|---|
| 两个页面同时保存 | 使用版本号乐观锁；后提交者看到版本冲突并重新加载 |
| 自定义说明包含指令注入 | 作为低优先级行为数据处理，拒绝覆盖高优先级规则 |
| 预览失败 | 保留表单，显示静态示例并提示预览暂不可用 |
| 删除禁忌项 | 仅影响未来输出，不重写历史消息 |

### 规则优先级

```text
安全与证据规则
> 用户当前明确指令
> 提醒和日历事实
> 助手性格配置
> 自动蒸馏的用户画像
```

## 功能节点三：我的画像

### 页面交互

- **页面入口**：导航「助手」→「我的画像」。
- **展示内容**：人格、价值观、目标、习惯、技能、知识、思维模式、偏好、情绪基线九个维度，每项显示 evidence 和版本。
- **操作项及点击效果**：点击 evidence → 打开来源；点击「纠正」→ 输入更正并要求选择依据；点击「删除」→ 二次确认后停用该画像条目；点击「重新蒸馏」→ 从有效记忆生成新版本。
- **特殊状态提示文案**：无画像显示“还没有足够信息形成画像”；缺失来源显示“这条理解缺少有效依据，建议删除或重新蒸馏”。

#### 功能联动

- 画像纠正或删除 → 后续聊天、推荐和主动建议使用新版本。
- 助手性格变化 → 不修改用户画像。
- 删除来源记忆 → 关联画像条目标记 evidence 缺失，不静默保留为确定事实。

#### 异常与边界

| 场景 | 预期处理 |
|---|---|
| 并发蒸馏 | 同一时间只允许一个任务运行 |
| 删除被引用画像 | 保留历史版本，当前版本停用 |
| 纠正无依据 | 允许标记为“用户明确声明”，不可冒充自动推断 |

## 功能节点四：桌面弹幕

弹幕是助手离开页面后的主动表达，不承载主动聊天回复。

### 事件来源

| 类型 | 内容 | 默认优先级 |
|---|---|---:|
| 到期提醒 | 临近或到期事项 | 高 |
| 主动建议 | 有 evidence 的行动建议 | 中 |
| 环境感知 | 高置信屏幕或音频点评 | 中 |
| 场景陪伴 | 游戏短评、课程关键提示 | 低 |

### 页面交互

- **页面入口**：导航「设置」→「弹幕」；托盘菜单提供常用开关。
- **展示内容**：连接状态、启用状态、安静模式、最近投递记录；外观配置包括位置、字号、透明度、速度和主题。
- **操作项及点击效果**：点击「测试弹幕」→ 后端发送标记为测试的短消息；点击「暂停 30 分钟」→ 页面与托盘同步暂停时间；点击「安静模式」→ 只放行高优先级到期提醒；调整外观 → 页面预览立即更新，保存后广播给弹幕壳。
- **特殊状态提示文案**：弹幕壳未连接显示“桌面弹幕未连接，页面功能不受影响”；暂停显示“弹幕已暂停至 HH:mm”。

#### 功能联动

- 页面主动聊天 → 不产生弹幕事件。
- 主动程度变化 → 重新过滤未投递队列。
- 进入全屏、会议或演示 → 自动或手动进入安静模式；退出后恢复此前模式，不补发过期消息。
- 弹幕壳断开 → 页面继续工作；恢复后只接收仍在有效期内的消息。

#### 异常与边界

| 场景 | 预期处理 |
|---|---|
| 多条消息同时到达 | 高优先级先显示；默认同时最多 1 条，其他排队 |
| 消息积压 | 过期直接丢弃，不在重连后刷屏 |
| 文本过长 | 后端生成不超过 40 汉字的展示文案；短提醒原样保留，不因长度丢弃；壳只做最终安全截断 |
| 多显示器 | 默认当前活动显示器；配置可固定显示器 |
| 全屏游戏 | 透明、置顶、点击穿透，不抢焦点 |
| 任务栏或输入区遮挡 | 根据工作区边界约束位置，拒绝越界配置 |

### 极薄 Electron 壳职责

保留：

- 单实例锁。
- 透明置顶、点击穿透弹幕窗口。
- 托盘：打开助手、暂停弹幕 30 分钟、安静模式、退出。
- 连接 PA `/ws/live`、断线重连、展示配置缓存。

删除：

- 桌宠窗口、资源、拖拽、命中测试和宠物状态。
- `Ctrl+M` 桌宠聊天。
- 独立 Jarvis FastAPI、模型下载、Worker 启动和后端健康管理。
- Jarvis 文件记忆、课程库和生图入口。
- Electron 中的业务配置与智能决策。

## 功能节点五：状态与感知

### 页面交互

- **页面入口**：今天页顶部状态区；「设置」→「运行状态」。
- **展示内容**：PA 后端、助手模型、环境感知、弹幕壳四个状态及最近错误。
- **操作项及点击效果**：点击「开启环境感知」→ 明确提示将加载本地模型，确认后启动 Worker；点击「关闭环境感知」→ 停止采集并退出 Worker；点击「重试」→ 仅重试失败组件；点击「查看详情」→ 展示可复制的错误信息。
- **特殊状态提示文案**：默认显示“环境感知未开启，不占用本地模型资源”；本地模型失败显示“本地模型启动失败，未切换云端”；弹幕壳断开显示“桌面弹幕未连接”。

#### 功能联动

- 开启感知 → Worker 启动成功后才把状态设为运行。
- 关闭感知 → Worker 必须退出并释放显存；页面聊天继续使用当前非本地后端。
- 选择本地模型作为聊天后端 → 明确提示该操作也会加载 Worker，但不自动开启屏幕或音频采集。
- PA 后端断开 → 弹幕壳停止展示新消息并退避重连，不自行启动 PA。

#### 异常与边界

| 场景 | 预期处理 |
|---|---|
| Worker 启动超时 | 状态为错误，清理半启动进程，允许重试 |
| Worker 关闭失败 | 强制终止其拥有的进程树并报告结果 |
| 显存不足 | 启动前提示，启动失败后不回退 CPU 或云端 |
| PA 与弹幕壳版本不兼容 | 拒绝连接并提示升级，不忽略未知关键字段 |

## 弹幕事件契约

PA `/ws/live` 增加统一 `barrage` 事件，避免壳自行解释多种业务事件：

```json
{
  "type": "barrage",
  "data": {
    "id": "stable-id",
    "text": "十分钟后开会，资料还没打开。",
    "kind": "reminder",
    "priority": "high",
    "expires_at": "2026-07-31T09:55:00+08:00",
    "personality_version": 3,
    "style": "restrained"
  },
  "ts": "2026-07-31T09:45:00+08:00"
}
```

壳只执行连接、过期判断、队列、展示和外观；业务是否应该发弹幕由 PA 后端决定。

## 数据边界

新增 PA 数据：

- 助手性格当前版本与历史版本。
- 弹幕设置、安静模式和暂停截止时间。
- 弹幕投递记录，仅保存事件 ID、类型、时间、结果和 evidence ID，不复制完整记忆正文。

继续使用：

- PA `persona_versions` 作为用户画像历史。
- PA chat log、segments、memories、events、reminders、wiki。

废弃：

- Jarvis `events.jsonl`、`summary.json`、`facts.json`、`index.json`、`daily/` 作为运行时真相源。
- Jarvis 独立课程与记忆业务层。

## 验收标准

1. 仅启动 PA 后端即可使用页面聊天、助手性格、用户画像、记忆、日历、提醒和设置。
2. 启动弹幕壳不会启动第二套 FastAPI、模型下载器或 MiniCPM-o Worker。
3. 页面主动聊天回复不会产生桌面弹幕。
4. 到期提醒、主动建议、环境感知和场景陪伴可按规则显示全桌面置顶弹幕。
5. 弹幕透明、置顶、点击穿透，不抢焦点；托盘能打开页面、暂停、切安静模式和退出。
6. 助手性格保存后同时影响未来页面回复与弹幕措辞，但不改变事实、证据、优先级和提醒时间。
7. 用户画像与助手性格独立版本化；修改一方不覆盖另一方。
8. 本地引擎默认关闭；关闭感知后 Worker 退出且显存释放。
9. PA 断线、弹幕壳断线、本地模型失败均有独立、明确状态；无静默云端回退。
10. Electron 中不再存在桌宠、桌宠聊天、独立后端、模型管理或 Jarvis 记忆和课程入口。

## 分阶段交付

1. 后端统一：助手性格、弹幕策略与事件契约；补足感知关闭释放 Worker。
2. Web 主界面：今天、连续聊天、性格工作室、我的画像、统一状态。
3. 弹幕壳瘦身：删除桌宠和独立后端，只连接 PA。
4. 生活空间与迁移：重组记忆、日历、提醒、知识和设置；移除废弃 Jarvis 业务路径。
5. 真实验证：单后端、单 Worker、跨应用弹幕、断线重连、显存释放。

## 已决策事项

- 弹幕必须支持全桌面置顶，因此保留极薄 Electron 壳。
- 页面是唯一主交互面，Electron 不内嵌主页面。
- 主动聊天只在页面显示，不同步弹幕。
- 助手性格采用预设加结构化微调，不做裸提示词或多角色档案。
- 本地引擎默认关闭，不随页面或弹幕壳启动。
